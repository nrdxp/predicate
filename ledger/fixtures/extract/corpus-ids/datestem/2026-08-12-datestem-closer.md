# Date-prefixed stems — the later document

`signer:: agent/composer` · `at:: 5b2e7d4`

This fixture is SYNTHETIC. It pairs with 2026-08-11-datestem-open.md and is
extracted with it as one corpus.

Every other corpus here spells its stems in letters, which no document in the
landed record does. The stem a reference carries is a file stem, and file
stems lead with a date, so a stem that admitted letters alone would strand
every cross-document reference the record actually writes — while every
alphabetic fixture stayed green. Both edge kinds cross by a dated stem below,
because they fail differently: the closure edge would be reported, and the
derivation edge would be filed as external provenance and pass in silence.
