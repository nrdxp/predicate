# A qualified id resolving nowhere

`signer:: agent/composer` · `at:: 3f1c9a2`

This fixture is SYNTHETIC and is a single document: the qualified references
in it name a stem no document of the corpus carries.

A qualified reference is an authorial declaration that its target is in the
corpus. Where it is not, the declaration is wrong and the record must say
so. The failure mode pinned here is the quiet one — a reference the resolver
cannot place being filed as external provenance, where it reads as a
deliberate pointer outside the record rather than as the mistake it is. Free
prose and wikilinks are external because their author wrote them that way; a
bracketed id is not, and the two must not be collapsed.

The resolvable half of the same value survives. An unplaceable reference is
reported, and reporting it is no reason to drop the edges beside it.
